
## Homework 8 – World Bank Indicator Analysis 🌍

This project is part of CMSC 408 and focuses on analyzing the World Bank’s **World Development Indicators (WDI)** dataset using SQL. The assignment strengthens data analysis skills by using real-world development data in a structured way.

---

## 🧠 Objective

The goal of this assignment is to improve SQL skills and apply them to a large dataset by:

- Writing queries using `SELECT`, `WHERE`, `GROUP BY`, and `ORDER BY`
- Working with subqueries and conditional logic via `CASE`
- Creating pivot-style summaries and handling missing values
- Analyzing trends across world regions and income groups

---

## 🔍 What I Did

- Connected to a SQL database using environment variables and helper functions
- Explored the `wdi_country` table to understand country-level information
- Identified non-countries and filtered the data accordingly
- Used aggregation to group countries by region and income category
- Built summary tables, pivot tables, and calculated percentages
- Updated data for accuracy and validated changes
- Completed 21 SQL tasks and wrote reflections on the learning process

---
